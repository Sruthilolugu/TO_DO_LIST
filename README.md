# TO_DO_LIST
TO_DO_LIST APP
This is a simple To-Do List web application built using HTML, CSS and JavaScript.
The user can add tasks, mark them as completed, delete tasks and the data will be saved in localStorage, so tasks remain even after refreshing the page.
Features

Add new tasks
1.Mark tasks as completed (click on item)
2.Delete tasks (click on × icon)
3.Tasks are saved in the browser using localStorage
4.Responsive design
 Files           Description                        
 -----------   ---------------------------------- 
 1.to.html        Main HTML structure of the page    
 2.style.css      Styling for the To-Do List UI      
 3.script.js      JavaScript logic (add/delete/save) 

How to Run

1.Place to.html, style.css and script.js in the same folder.
2.Open the file to.html in any web browser.
3.Type a task and click Add to insert a new task.
4.Click on a task to mark it as completed.
5.Click on the × icon to delete a task.
